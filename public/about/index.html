About TikZ Drawer

TikZ Drawer is a free browser-based visual editor for people who want to create diagrams visually and keep LaTeX TikZ as the editable output.

Open the editor View the source on GitHub

Why the project exists

TikZ produces excellent vector graphics for LaTeX, but positioning and iterating on a diagram entirely through code can be time-consuming. TikZ Drawer bridges the visual and textual workflows: users can compose a scene on a canvas, inspect the result and export ordinary TikZ code that remains theirs to edit.

The editor supports common shapes, text, connectors, graph presets, layers, alignment, snapping, import and export workflows. It runs online without requiring a local installation and is designed to remain useful on desktop, tablet and mobile-sized screens.

Creator and source

TikZ Drawer is created and maintained by Aniol0012. The source code, issue tracker and release history are available in the public GitHub repository. Bugs, feature proposals and technical contributions can be discussed there.

What TikZ Drawer is — and is not

TikZ Drawer is a visual authoring tool and code generator. It does not replace the LaTeX compiler or the full TikZ ecosystem. After exporting, compile the figure in your own LaTeX environment and review it with the packages, fonts and document class used by your project.

Generated drawings are standard text-based TikZ, so they can be version-controlled, refined manually and shared independently of the web application.
